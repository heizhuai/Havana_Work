# 塔楼模块化低模 T01–T11

使用 Blender 5.2.3 LTS 创建。11 个独立模块，共 **5,532 三角面**。根据六视图轮廓建模，照片仅用于建筑风格参考；没有实测标定，尺寸为可统一缩放的假定米制尺寸。

## 文件

- `Tower_Modular_T01_T11.blend`：可编辑低模、命名资产、UV0、UV1、内置棋盘材质与拼装示例。
- `exports/`：每模块一份 FBX、GLB、OBJ/MTL。导出文件已三角化；每份位于本地原点，物体缩放为 1。
- `uv/`：每模块 2048×2048 UV 线框 PNG、透明背景 SVG，以及用于验证的 UV 坐标 JSON。
- `Overview_clay.jpg`：低模形体总览。`Overview_checker.jpg`：UV 棋盘总览。
- `previews/`：各件形体、UV 棋盘、钟口内腔、L形墙内侧及示意拼装图。
- `mesh_report.json`、`uv_validation.json`、`file_validation.json`：网格、UV、文件检查结果。

## Blender 内使用

- `01_ASSETS_T01_T11` 是 11 个生产模块。为便于检查，工程中按两排摆放；画廊平移不是导出位置。
- `02_ASSEMBLY_EXAMPLE` 是 X=36m 处的示意拼装，使用共享网格副本。通过集合可独立显示；示例部分角件沿高度缩放，仅用于说明拼装关系。
- `90_PRESENTATION` 只含相机、灯光、标签，不是生产模块。
- 资产正面朝 **-Y**，高度朝 **+Z**。墙模块原点为底边中心的外墙面；L形转角原点为外角底点。导出已在本地原点。
- 主墙直段宽 4m、墙厚 0.5m；L形转角腿长 1.2m，内侧厚 0.5m；直段与转角端面可按 0.1m 网格对接。檐口剖面沿正面外挑，直段端头保持平切以拼接。实际外包尺寸包含装饰外挑。
- `T02` 保留上下两个贯穿拱窗，并含上窗的七杆格栅；`T09` 作为可复用格栅独立提供。
- `T10` 钟口内侧、内腔和钟舌均有真实几何。钟体为 24 边旋转轮廓。

## UV 与材质

- **UV0**：逐模块独立 0–1 展开，岛无重叠，岛间 padding 0.008（2048 参考尺寸约 16px）。没有跨模块共用图集。
- **UV1_Lightmap**：复制独立 UV0 作为无重叠的 lightmap 起点；在引擎中按目标 lightmap 分辨率重新生成合适间距。
- UV 岛按几何比例统一面积后打包；细长壁柱的打包利用率较低。各模块纹素密度不同，目标贴图分辨率应按资产大小分配；尚未统一为整套固定 texel density。
- 工程内 `UV_CHECKER_2048` 和 `UV CHECK | inspection only` 用于检查拉伸。预览由该 UV 实际渲染。
- 仅提供石材、铁、铜、木的基础色材质；未制作照片投射、PBR贴图、高模烘焙、LOD、碰撞或引擎专用设置。
- 网格使用硬表面平面着色，钟体局部平滑。保留分离零件及装饰接合处的合理相交，不是单一布尔融合水密实体。

## 已验证

11 个模块均无非流形边、零面积几何面；UV0 均在 0–1 内，无零面积 UV 三角形，逐三角形相交检查无面积重叠。保存后重新打开 .blend 并检查导出文件。预览已人工检查主要轮廓、L形结构、双窗、格栅数量和钟口内部。

拼装图仅为模块使用示例，不代表照片的精确测绘复原。原六视图隐藏面及厚度存在推演，本套采用统一合理结构。
