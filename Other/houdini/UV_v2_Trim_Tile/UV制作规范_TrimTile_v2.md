# B01 建筑模组 UV 制作规范 v2

适用：B01_Door_01 与 B01_Window_01。流程：建筑 Trim Sheet + 平铺材质。以下数值是这两套资产的项目约定，并非所有游戏项目统一采用的标准。

## 1. 坐标与质量基准

| 项目 | 本项目规则 |
|---|---|
| 模型 | 保留原版几何、尺寸、分件及倒角，不通过改模型掩盖 UV 问题 |
| 单位 | 米，Z 向上，模型正面为 -Y |
| 纹素密度 | 2048×2048 贴图基准下，主体目标 512 px/m，即 5.12 px/cm |
| 密度容差 | 主体以 ±10% 验收；微小倒角端点和曲线转角单独检查，不为数字强行压扁轮廓 |
| 棋盘格 | 检查图每格 32 px，对应目标密度下 6.25 cm；编号用于判断方向和重复 |
| 最终材质 | 不制作材质；棋盘格仅用于检查，已从交付 Blender 的材质槽中移除 |

平铺材质如果改用 1K，保持当前 UV 会变为 256 px/m；改用 4K 会变为 1024 px/m。若模型整体缩放，应相应调整 UV 或材质平铺次数，以维持密度。

## 2. UV 通道

| Blender 名称 | FBX / 常见引擎索引 | 用途及约束 |
|---|---:|---|
| UV0_TrimSheet | 0 | 默认纹理通道；按共享条带模板取样；U 沿构件长度，V 沿剖面；重复件允许有意重叠；可沿 U 重复，V 不跨条带 |
| UV1_Tile | 1 | 按实际尺寸展开的平铺通道；不含 Trim 条带偏移；用于木材、石材、涂层等平铺表面；允许重叠及重复 |
| UV2_UniqueBake | 2 | 独立的 0–1、不重叠烘焙辅助通道；不与纹理 UV 混用；若需烘焙光照，应按目标 lightmap 分辨率重新检查间距 |

UV0 与 UV1 不以“占满 0–1、完全不重叠”作为验收目标。建筑共享纹理流程的目标是方向、尺度、复用和条带对应关系。UV2 才检查唯一性。

## 3. 切缝与展开规则

1. 长框、窗套及线脚：按真实构件的转角拆分，沿长度展开成直条；长边保持平直，斜接头可保留梯形端部，不把整圈框体做成大空心岛。
2. 百叶：每片沿长度方向取样，剖面沿 V 展开；相同百叶使用同样的位置和方向，不为每片占据独立纹理区域。
3. 胶囊形装饰格：直段与圆弧在自然过渡处分开；圆弧按弧长展开，保留几何曲率带来的轻微横向差异，避免整圈形成细长空心岛。
4. 平面与端盖：保持平面投影、统一尺度；优先沿构件长轴安排纹理方向；小端盖与主体分开取样。
5. 小倒角：尽量跟随所属条带；局部折叠或退化的倒角端面改为独立的小平面 UV，不把错误藏在倒角中。
6. 两套模组共用同一套 Trim 分区；若未来增加破损、独立污渍和差异，可通过 decal、顶点色或额外遮罩完成。

## 4. 共享 2K Trim 模板

图片坐标从上往下，以下像素坐标从 UV 的 V=0 底部往上计算。每条带上下各保留 8 px 保护区，相邻有效区间隔为 16 px；4K 等比翻倍，1K 等比减半。制作真实贴图时，条带边缘应做颜色扩张，U 方向需可无缝平铺。

| ID | 分区 | 像素范围 | 有效 V 范围 |
|---:|---|---|---|
| 0 | 平面与端盖 | 0–512 | 8/2048 ～ 504/2048 |
| 1 | 主门窗套线脚 | 512–1024 | 520/2048 ～ 1016/2048 |
| 2 | 顶部檐口、窗台剖面 | 1024–1408 | 1032/2048 ～ 1400/2048 |
| 3 | 门窗扇、嵌板边框 | 1408–1664 | 1416/2048 ～ 1656/2048 |
| 4 | 胶囊形装饰格 | 1664–1792 | 1672/2048 ～ 1784/2048 |
| 5 | 百叶片 | 1792–1920 | 1800/2048 ～ 1912/2048 |
| 6 | 细线脚预留 | 1920–1984 | 1928/2048 ～ 1976/2048 |
| 7 | 附件预留 | 1984–2048 | 1992/2048 ～ 2040/2048 |

这是一套通用表面细节条带模板，现有线脚由几何表达。尚未制作或烘焙某一特定剖面的法线贴图；后续若要用法线贴图表达特定凹槽，应为不同剖面分配专用条带，而不是直接给所有剖面套同一条法线。

对象自定义属性 `surface_family` 标记了 PaintedWood、Stone 或 Glass；面属性 `trim_band` 标记了条带 ID，方便继续选择和分配。不同材质家族可以使用相同布局的贴图变体。玻璃部件单独保留，最终制作时可直接分配玻璃材质。

## 5. 验收与交付

- 保存文件重新打开后检查：模型位置、顶点与面数一致；零材质槽。
- UV0 / UV1：无塌缩三角形、无单面内折叠；主体尺度一致，纹理长轴方向明确；V 不越过整个模板边界。
- UV0：百叶重复取样、条带归属和保护区由分区图与棋盘格对照检查。
- UV2：无越界、无面积重叠，作为独立烘焙辅助；不把它标作已经按低分辨率验收的光照 UV。
- Blender 文件内默认启用 UV0_TrimSheet。FBX 保留全部三个 UV 通道，材质中应明确选用对应通道。
- PNG 模板和棋盘格是技术辅助图，不是成品材质。文件夹内附模型棋盘格预览、UV 叠加图和检查记录。
