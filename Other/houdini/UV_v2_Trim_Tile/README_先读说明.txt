B01 UV v2 — Trim Sheet／平铺工作流

先阅读 UV制作规范_TrimTile_v2.md。此版本按建筑共享纹理流程重做，默认使用 UV0_TrimSheet。
纹理 UV 的重复与重叠是有意设计；UV1_Tile 用于按实际尺寸平铺；UV2_UniqueBake 是独立烘焙辅助。
没有制作成品材质；Blender 交付文件内材质槽为零。棋盘格 PNG 仅用于质量检查。

UV0 取样：2048 基准，目标 512 px/m，条带上下各留 8 px。保留现有几何线脚，不含已烘焙的剖面法线贴图。
主体密度验收统计（主体定义为单三角形面积 > 0.001 m²）：
B01_Door_01：面积加权平均 516.7 px/m；主体 99.75% 表面积落在 512±10%；模型几何一致；零塌缩、零单面内折叠。
B01_Window_01：面积加权平均 516.7 px/m；主体 99.74% 表面积落在 512±10%；模型几何一致；零塌缩、零单面内折叠。

Blender 文件保留三个 UV 通道，FBX 同步保留。对象 surface_family 属性和面 trim_band 属性可辅助后续分配。
共享模板图从图片底部对应 UV V=0 开始编号；检查图上的 00～07 是条带编号。
UV2 为唯一烘焙辅助，不作为已验收的低分辨率光照 UV。若项目使用静态烘焙光照，请按目标 lightmap 分辨率再作专门设置。
法线的镜像切线空间及最终材质效果需在实际引擎里验收；当前阶段检查的是模型 UV，而非成品材质。
